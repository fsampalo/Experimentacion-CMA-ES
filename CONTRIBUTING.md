# Contributing

Thanks for your interest in improving this project.

1. Open an issue or a small pull request describing the change (bug fix, doc fix, or reproducibility improvement).
2. Keep changes focused; this repository is intentionally compact for coursework and competition review.
3. Run `python scripts/smoke_test.py` locally after editing dependencies or environment assumptions.
4. If you change the experiment protocol in `cma_sampling.ipynb`, update `main.tex` and the README so they stay aligned.

By submitting a contribution, you agree that your changes are licensed under the same terms as this repository (MIT).
